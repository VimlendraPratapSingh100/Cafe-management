# 🍽️ Python Restaurant Ordering System

## 📌 Project Overview

This is a simple **Restaurant Ordering System built using Python**.
The program displays a restaurant menu, allows the user to order up to **two items**, checks whether the selected items are available, and calculates the **total bill amount**.

This project is created as a beginner-level Python project to practice basic programming concepts.

## 📋 Menu

| Item      | Price |
| --------- | ----: |
| 🍕 Pizza  | Rs 40 |
| 🍝 Pasta  | Rs 50 |
| 🍔 Burger | Rs 60 |
| 🥗 Salad  | Rs 70 |
| ☕ Coffee  | Rs 80 |
| 🍵 Tea    | Rs 55 |

## ⚙️ Features

* Displays the restaurant menu
* Takes the first item from the user
* Checks item availability
* Allows the user to add a second item
* Calculates the total order amount
* Displays the final bill amount
* Shows a message if an item is unavailable

## 🛠️ Technologies Used
